# Benchmark Visualization System

Publication-quality figures for the Central Asian Voice Benchmark,
generated **directly from the frozen benchmark results**.

## Scope & integrity

- Reads only `results/phase2_full/phase2_trackb_results.jsonl` (2,400 records)
  and `results/phase3a/phase3a_trackb_results.jsonl` (468 records).
- No benchmark methodology, frozen results, or statistical tests are modified.
- No network access, no API calls, no money spent.
- Every displayed number is computed at figure-generation time from the JSONL
  by `data.py`. Nothing is hand-typed except a short list of verbatim
  [report] constants (list prices, version identifiers, Phase 1 corpus sizes)
  clearly marked in the source.
- Two verification scripts cross-check recomputed values against the frozen
  final report (`research/final_benchmark_report.md`):
  - `verify_against_report.py` — 41/41 checks (canonical figure set).
  - `verify_publication.py` — 55/55 checks (publication / Kaggle-hub set).

## Two figure systems (same source of truth)

### 1. Canonical figures (`figures/`)
Generated by `make_figures.py` (uses `data.py` + `style.py`). These are the
verified, traceable figures aligned one-to-one with the report sections.

| File | Communicates |
|---|---|
| `01_flagship_uzbek_detection_failure` | **Flagship.** Uzbek AUTO detection 27% vs Kazakh 99%, and the +100% relative WER cost of Uzbek misdetection. |
| `02_detection_outcomes_by_language` | Detection accuracy per target language; what Uzbek is mistaken for (Turkish, English, Russian...). |
| `03_auto_vs_hint_paired` | SECONDARY AUTO vs HINT analysis with paired per-utterance lines and difference distribution. Explicitly annotated as non-significant (all p > 0.05, CIs include zero). |
| `04_r1_routing_primary` | PRIMARY R1 routing test: routed ≈ always-HINT; success criterion (mean(d) ≤ −0.030 AND p < 0.05) NOT MET. Presented as a null result. |
| `05_phase2_provider_comparison` | Phase 2 descriptive provider comparison (ElevenLabs Scribe v2 vs GCS Chirp 2), WER + latency. |
| `06_research_design_overview` | Research design story: Phase 2 → detection analysis → routing test; pilot-study scope disclaimer. |
| `07_phase2_accuracy_vs_latency` | WER vs mean latency for Phase 2 cells only (same corpus). No efficiency score derived. |

### 2. Publication / Kaggle-hub figures (`figures/publication/`)
Generated by `make_publication_figures.py` (reuses `data.py` + `style.py`,
reference-aesthetic matching `reference pics/`). Nine cohesive figures covering
the full analysis surface requested for the Kaggle research hub.

| File | Communicates | Primary / Secondary |
|---|---|---|
| `00_benchmark_overview` | Executive one-pager: KPIs, phase map, key finding, scope. | — |
| `01_provider_comparison` | Model/provider comparison, Phase 2 vs Phase 3A. | both labelled |
| `02_uzbek_vs_kazakh_detection` | Uzbek vs Kazakh language detection + cost of misdetection. | descriptive |
| `03_auto_vs_hint` | AUTO vs HINT paired analysis. | **SECONDARY** |
| `04_routed_vs_hint` | ROUTED vs HINT (R1 routing). | **PRIMARY (null)** |
| `05_cost_vs_wer` | Accuracy vs cost per call (bubble = latency). | descriptive |
| `06_latency_vs_wer` | Latency vs WER, per-utterance (Phase 3A) + Phase 2 means. | descriptive |
| `07_error_analysis` | WER ≥ 1.0 records, apostrophe confound, failure taxonomy. | diagnostic |
| `08_reproducibility` | Dataset integrity, PASS ledger, provenance SHA ledger. | — |

All figures in both systems share the same semantic color system:
AUTO — steel blue `#3E6D9C`, HINT — amber `#D9822B`, ROUTED (R1) — green
`#4F8A5B`, Uzbek — red `#B0413E`, Kazakh — teal `#2E7D6B`.

Each figure is written as PNG (Kaggle/web), SVG and PDF (publication).

## Scientific-honesty conventions

- Phase 2 and Phase 3A are visually separated; the PRIMARY (routing) and
  SECONDARY (AUTO vs HINT) tests are explicitly labelled on every panel.
- Sample sizes (n) are shown wherever a WER/statistic is presented.
- Scope is constrained to Uzbek and Kazakh only — two of many Central Asian
  languages. No broader Central Asian coverage is implied; contamination risk
  is MEDIUM (public corpora), disclosed throughout.

## Reproduce

```bash
cd research/visualizations
uv venv .venv                      # once
uv pip install --python .venv/Scripts/python.exe matplotlib numpy
.venv/Scripts/python.exe verify_against_report.py   # 41/41 checks must pass
.venv/Scripts/python.exe verify_publication.py       # 55/55 checks must pass
.venv/Scripts/python.exe make_figures.py            # writes figures/
.venv/Scripts/python.exe make_publication_figures.py # writes figures/publication/
```
